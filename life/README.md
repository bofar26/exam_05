# life 考试复习

答案由 `life.c` 和 `life.h` 组成，只使用题目允许的函数。提交时两个文件一起交。

`life.h` 集中包含标准头文件，用 `#ifndef / #define / #endif` 防止重复包含。三个辅助函数只在 `life.c` 内使用，因此保留为 `static`，不需要在头文件中声明。

## 编译与运行

在 `life` 目录下执行：

```sh
cc -Wall -Wextra -Werror life.c -o life
echo 'dxss' | ./life 3 3 1 | cat -e
```

结果（空格也是输出的一部分）：

```text
   $
OOO$
   $
```

手动输入时，输完命令按 Enter，再按 Ctrl+D，程序才开始演化。

## 记住四步

1. `calloc` 创建两个全为 0 的棋盘。
2. `draw` 读取命令，画出初始状态。
3. 每轮先 `step` 算出下一轮，再交换两个指针。
4. 输出当前棋盘，释放两个数组。

## 三个核心记忆点

**坐标转下标：** `board[y * width + x]`，其中 `x` 是列，`y` 是行。

**画图：** 从左上角开始，笔最初抬起。`x` 切换落笔/抬笔；落笔时立即把当前位置设为 1，移动时继续画。抬笔不擦除。换行等其他字符不改变状态。题目没有明确规定笔越界时的行为，这个版本采用“到边界就停住”。

**生命规则：** 周围八格，不包括自己；棋盘外视为死细胞。

| 活邻居数 | 下一轮 |
| --- | --- |
| 3 | 一定活 |
| 2 | 保持原状态 |
| 其他 | 一定死 |

因此只需记住：

```c
next[i] = (n == 3 || (board[i] && n == 2));
```

必须先把所有结果写入 `next`，不能边计算边修改 `board`，否则后面的格子会读到本轮刚改过的数据。

交换指针后，`board` 就是最新棋盘。下一轮会覆盖 `next` 的每一格，所以不用清空它。

## 容易漏的细节

- `iterations == 0` 时，仍然读完命令并输出初始棋盘。
- 每行输出完整的 `width` 个字符，包括末尾空格，再输出换行。
- 整个棋盘都死了，也要输出空格和换行。
- 只在全部迭代完成后输出一次。

本地题目示例的空格似乎被压缩了，应以棋盘宽度和命令轨迹为准。
