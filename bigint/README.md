# bigint 考试复习

提交文件是 `bigint.hpp` 和 `bigint.cpp`。`main.cpp` 是从题目原样提取的示例，供本地运行；本说明不需要提交。

## 1. 先记住数据怎么存

用 `std::string digits` **正序**保存十进制数字：

```text
42   → "42"
1337 → "1337"
0    → "0"
```

始终保持两条规则：字符串不为空；除了 `"0"`，没有前导零。因此输出可以直接打印字符串，比较也能直接利用长度和字典序。

整个大数不会被转换成普通整数，所以超过 `SIZE_MAX` 仍然可以精确运算。构造函数接受 `std::size_t` 范围内的非负整数，更大的数可以通过加法和十进制位移构造。题目不要求负数、减法、乘法或字符串构造函数。

## 2. 核心算法：加法、比较、位移

### 加法：从右往左，取余存位，整除进位

```text
    999
  +   1
  -----
   1000
```

`i` 和 `j` 表示两个字符串还剩多少位。需要取下一位时，用 `digits[--i]`，这样不会访问负下标。字符减去 `'0'` 得到数字，数字加上 `'0'` 变回字符。

每轮计算：

```cpp
sum = carry + 本轮左边数字 + 本轮右边数字;
本位 = sum % 10;
carry = sum / 10;
```

某一边读完，就不再加它。循环条件必须包含 `carry`，否则会漏掉 `999 + 1` 最后的进位。结果按个位、十位、百位依次追加，最后 `reverse` 一次。

`+=` 直接复用 `+`：`*this = *this + other`。这样 `a += a` 也正确，因为先算完结果，再赋值。

### 比较：先长度，后字典序

没有前导零时：

- 位数不同：位数少的更小，例如 `99 < 100`。
- 位数相同：字符串字典序就是数值顺序，例如 `"123" < "132"`。

只需要认真写 `==` 和 `<`，其余复用：

| 运算 | 实现思路 |
| --- | --- |
| `a != b` | `!(a == b)` |
| `a > b` | `b < a` |
| `a <= b` | `!(b < a)` |
| `a >= b` | `!(a < b)` |

不能只比较字典序，因为 `"99"` 的字典序大于 `"100"`，数值却更小。

### 十进制位移：左补零，右删尾

```text
42 << 3   → "42" 末尾补 3 个零 → 42000
1337 >> 2 → "1337" 删掉末尾 2 位 → 13
42 >> 2   → 0
42 >> 20  → 0
0 << 3    → 0
```

移动零位不改变数值。右移达到或超过总位数时，保存 `"0"`，不能留下空字符串。零左移仍然是 `"0"`，不能变成 `"0000"`。

**本题的位移参数用 `const bigint&`**，因为示例有 `d >>= (const bigint)2`。普通的 `b << 10` 也能使用：构造函数没有 `explicit`，所以 `10` 可以隐式构造成 `bigint`。

`boundedShift(limit)` 是一个边界辅助函数，返回“位移次数与 limit 中较小的值”。它从左往右读数字，在执行 `count * 10 + digit` 前检查会不会超过上限：

```cpp
count > limit / 10
|| (count == limit / 10 && digit > limit % 10)
```

超过就直接返回 `limit`，因此位移次数本身再大，也不会在转换时溢出。

- 右移只需要知道次数是否达到字符串长度，所以令 `limit = digits.size()`。
- 左移令 `limit = 剩余可容纳字符数 + 1`；返回值超过剩余空间时，抛出 `std::length_error`。实际分配内存仍可能失败，和其他使用字符串的程序一样。

记忆时先掌握“补零、删尾”，再理解这个辅助函数如何处理极大的次数。

## 3. 运算符返回值：改自己返引用，不改自己返新值

| 类型 | 返回值 | 成员函数尾部 `const` |
| --- | --- | --- |
| `+`、`<<`、`>>` | `bigint`，返回新对象 | 有 |
| `=`、`+=`、`<<=`、`>>=` | `bigint&`，返回 `*this` | 无 |
| 前置 `++a` | `bigint&`，返回修改后的自己 | 无 |
| 后置 `a++` | `bigint`，返回修改前的副本 | 无 |
| 六种比较 | `bool` | 有 |

前置：先加一，再返回自己。后置：先保存旧值，再调用前置，最后返回旧值。后置声明中的 `int` 是区分两种重载的占位参数：

```cpp
bigint& operator++();    // ++a
bigint operator++(int);  // a++
```

`+` 和比较等操作不改当前对象，必须加 `const`，才能用于题目里的 `const bigint a(42)`。

普通位移也复用复合位移：复制当前对象，对副本执行 `<<=` 或 `>>=`，返回副本。

## 4. 两种 `<<` 不要混淆

```cpp
b << 10;        // bigint 的成员运算符：十进制左移
std::cout << b; // 非成员运算符：输出 bigint
```

输出运算符左边是 `std::ostream`，因此写成非成员函数。用 `friend` 允许它读取私有的 `digits`；返回 `std::ostream&`，才能继续 `std::cout << a << b`。

拷贝构造、赋值和析构都按普通值类型处理：`std::string` 自己管理内存，不需要手写 `new` 或 `delete`。

## 5. 编译与题目输出

在 `bigint` 目录执行：

```sh
c++ -std=c++98 -Wall -Wextra -Werror -pedantic bigint.cpp main.cpp -o bigint_demo
./bigint_demo
```

题目没有指定 C++ 标准；这份实现兼容 C++98，也可以用较新的标准编译。

预期输出：

```text
a = 42
b = 21
c = 0
d = 1337
e = 1337
a + b = 63
(c += a) = 42
b = 21
++b = 22
b++ = 22
(b << 10) + 42 = 230000000042
(d <<= 4) = 13370000
(d >>= 2) = 133700
a =42
d =133700
(d < a) = 0
(d <= a) = 0
(d > a) = 1
(d >= a) = 1
(d == a) = 0
(d != a) = 1
```

`b++` 输出旧值 `22`，但之后 `b` 已经是 `23`，因此下一行用 `23` 左移。`d` 的复合位移会保留修改：先变成 `13370000`，再变成 `133700`。

## 6. 考前默写顺序

1. 类声明：字符串、构造/拷贝/赋值/析构、运算符签名。
2. 构造：`do-while` 取个位，最后反转。
3. 加法：两个剩余位数、一个进位、取余存位、整除进位、最后反转。
4. 复用加法写 `+=`，再写前置和后置 `++`。
5. 比较：长度优先，同长字典序；其余比较复用。
6. 位移：次数有界转换，左补零，右删尾，特别处理零。
7. 普通位移：复制、复合位移、返回副本。
8. 输出：打印字符串，返回流引用。

自查边界：`0 + 0`、`999 + 1`、`a += a`、移动零位、右移超过长度、零左移、`a <<= a`、`a >>= a`。最后两种情况要求先读完位移次数，再修改自身；当前实现遵守这一点。
